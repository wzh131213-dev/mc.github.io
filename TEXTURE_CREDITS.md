# Minecraft 26.3 texture source

Textures are sourced from **InventivetalentDev/minecraft-assets**, branch **26.3**.

- Source repository: https://github.com/InventivetalentDev/minecraft-assets/tree/26.3/assets/minecraft/textures
- Upstream project description: extracted Minecraft assets; versioned branches correspond to Minecraft versions.
- The build uses the upstream `assets/minecraft/textures/block` files for world block atlas generation and copies `assets/minecraft/textures/item` files for inventory item icons.
- Blockstate/model references are read from the matching Minecraft Java 26.3 client archive only to map each block face to its vanilla texture.

The repository is an asset extraction mirror, not a claim that Minecraft artwork is independently licensed by this project. Minecraft artwork remains subject to Mojang/Microsoft's applicable terms and guidelines.
